What's new since v1.3.2

- **Search layout hotfix**: the query pill no longer expands to fill the
  remaining screen. Its decoration now uses intrinsic height with a 48dp
  minimum, so the search bar stays compact while still allowing larger
  font content to grow without clipping.
- The v1.3.2 improvements to the unsaved-changes dialog, Settings, and
  responsive search behavior are otherwise unchanged.

**Downloads**

- **app-release.apk** — signed release build (recommended)
- **app-debug.apk** — debug build

Install: download an APK and open it on the device (allow "install unknown
apps" for this app). To update over an existing install, the APK must be
signed with the same key.
